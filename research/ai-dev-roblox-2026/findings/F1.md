# F1: Agent Skills ecosystem and reusable agent methodologies — the Claude "Agent Skills" open format (SKILL.md), official/community registries, notable published dev-workflow skills, discovery/install/versioning practices as of late 2026, plus adjacent formats (AGENTS.md, prompt/workflow libraries).

## Findings

### [1] The SKILL.md format is now a vendor-neutral open standard (agentskills.io, originally from Anthropic) adopted by 45+ agent products including Claude Code, Cursor, GitHub Copilot/VS Code, OpenAI Codex, Gemini CLI, Goose, Roo Code, Kiro, and JetBrains Junie
- quote: "The Agent Skills format was originally developed by Anthropic, released as an open standard, and has been adopted by a growing number of agent products. The standard is open to contributions from the broader ecosystem." (client showcase lists ~46 products incl. Cursor, VS Code, GitHub Copilot, ChatGPT & Codex, Gemini CLI, Claude Code)
- url: https://agentskills.io/home
- source_type: primary
- published: unknown (site live by Feb 2026; HN launch story 2026-02-03, 544 pts)
- confidence: high

### [2] A skill is a folder with a SKILL.md (YAML frontmatter + Markdown body); spec mandates `name` (≤64 chars, lowercase-hyphen, must match folder name) and `description` (≤1024 chars), with optional `license`, `compatibility`, `metadata` (author/version), and experimental `allowed-tools`; optional `scripts/`, `references/`, `assets/` subfolders
- quote: "Keep your main `SKILL.md` under 500 lines. Move detailed reference material to separate files." ... "1. Metadata (~100 tokens)... 2. Instructions (< 5000 tokens recommended)... 3. Resources (as needed)"
- url: https://agentskills.io/specification
- source_type: primary
- published: unknown (2026)
- confidence: high

### [3] Skills load via three-stage progressive disclosure (discovery: name+description at startup; activation: full SKILL.md on match; execution: bundled files on demand) — this is the core design claim that lets an agent keep many skills installed with minimal context cost; VS Code discovers skills in `.agents/skills/` by default
- quote: "VS Code looks for skills in `.agents/skills/` by default." and "Discovery — When the chat session started, the agent scanned default skill directories and found your skill. It read only the `name` and `description`"
- url: https://agentskills.io/skill-creation/quickstart
- source_type: primary
- published: 2026
- confidence: high

### [4] Anthropic's official example-skills repo (github.com/anthropics/skills) is one of the most-starred repos of 2026: 179,211 stars / 21,181 forks as of 2026-10-01 (created 2025-09-22); its `skill-creator` and `frontend-design` skills are top installs on skills.sh (395K and 941K installs respectively)
- quote: "\"stargazers_count\": 179211, \"forks_count\": 21181" ... leaderboard shows "frontend-design anthropics/skills 940.7K" and "skill-creator anthropics/skills 395.4K"
- url: https://api.github.com/repos/anthropics/skills and https://skills.sh
- source_type: primary
- published: retrieved 2026-10-01
- confidence: high

### [5] Vercel's skills.sh is the de-facto public registry/leaderboard: `npx skills add <owner/repo>` installs skills into 20+ agents (Claude Code, Cursor, Codex, Copilot, Windsurf, Gemini, Cline, Amp, OpenCode, Zed...); the leaderboard tracks 1.5M+ total installs all-time, dominated by vercel-labs, mattpocock/skills (4.4M aggregate), microsoft/azure-skills (8.0M aggregate), and anthropics/skills
- quote: "The Open Agent Skills Ecosystem ... Install them with a single command ... `$ npx skills add <owner/repo>`" and leaderboard header "All Time (1,518,675)"
- url: https://skills.sh
- source_type: primary
- published: retrieved 2026-10-01 (HN Show HN 2026-01-20)
- confidence: high

### [6] Skill discovery is moving toward well-known URL auto-discovery: Mintlify ships a machine-generated `/.well-known/skills/default/skill.md` on every docs site (aligned with a Cloudflare RFC, the agentskills proposal, and Vercel's skills CLI), so `npx skills add https://mintlify.com/docs` auto-discovers and installs; Mintlify explicitly deprecated its earlier `install.md` proposal in favor of skills
- quote: "All Mintlify documentation sites now contain a `/.well-known/skills/default/skill.md` file at their base URL. In accordance with the Cloudflare RFC, agentskills proposal, and Vercel skills CLI." and "`npx skills add https://mintlify.com/docs`"
- url: https://www.mintlify.com/blog/skill-md
- source_type: primary
- published: 2026-01-21
- confidence: high

### [7] Vercel's own agent evals (Next.js 16 APIs) found skills unreliable when passively available: skill present but unmentioned = 53% pass (no better than baseline; skill never invoked in 56% of cases); skill + explicit AGENTS.md instruction = 79%; an 8KB compressed docs index embedded in AGENTS.md = 100% — conclusion: passive context beats on-demand retrieval for broad framework knowledge, skills are better for explicit vertical workflows
- quote: "In 56% of eval cases, the skill was never invoked... Skill with explicit instructions 79% ... AGENTS.md docs index 100% (+47pp)" and "Skills work better for vertical, action-specific workflows that users explicitly trigger"
- url: https://vercel.com/blog/agents-md-outperforms-skills-in-our-agent-evals
- source_type: primary
- published: 2026-01-27
- confidence: high

### [8] The most influential engineering-workflow skill library is Addy Osmani's agent-skills (github.com/addyosmani/agent-skills, ~100K stars / 10.5K forks as of 2026-10-01): 20 skills organized around six SDLC phases with slash commands /spec /plan /build /test /review /ship /code-simplify, installable via Claude Code plugin marketplace (`/plugin marketplace add addyosmani/agent-skills`) or dropped into `.cursor/rules/` etc.; signature patterns: "process over prose", anti-rationalization tables (pre-written rebuttals to excuses agents use to skip steps), verification-as-exit-criterion, a router meta-skill for progressive disclosure
- quote: "Each skill includes a table of common excuses an agent (or a tired engineer) might use to skip the workflow, paired with a written rebuttal... Anti-rationalization tables are pre-written rebuttals to lies the agent hasn't yet told." and "/plugin marketplace add addyosmani/agent-skills"
- url: https://addyosmani.com/blog/agent-skills/ and https://api.github.com/repos/addyosmani/agent-skills
- source_type: secondary
- published: 2026-05-03
- confidence: high

### [9] TDD/debugging skills are a proven practitioner pattern: Jason Swett's public llm-skills repo (tdd, test-design-review, software-design-review SKILL.md files) encodes Kent Beck "Canon TDD" as a specify-encode-fulfill loop with a separate review skill that spawns a second agent to critique test design — and became his "default way of making any change"; obra/superpowers `systematic-debugging` and `brainstorming` are also top-250 installs on skills.sh (277K/382K)
- quote: "If you give your agent a skill that says nothing more than 'Follow Kent Beck's Canon TDD' then I suspect you'll be a good 60% of the way there... Test Design Review spawns a separate agent (in an effort to avoid bias)"
- url: https://www.saturnci.com/my-agent-skill-for-test-driven-development.html
- source_type: community
- published: 2026-05 (post); HN story 2026-06-04, 251 pts
- confidence: high

### [10] Versioning/sharing is git-based, not package-manager-based: skills are "portable, version-controlled folders" shared as GitHub repos, validated with the official `skills-ref validate ./my-skill` tool, versioned informally via `metadata: version` frontmatter; Claude Code additionally has an official plugin marketplace (anthropics/claude-plugins-official, 37,255 stars, created 2025-11-20) distributing plugins that bundle skills/commands/MCP servers, and a paid-skills marketplace experiment appeared Sep 2026 (skillbay.sh, "Craigslist for agent skills")
- quote: "Skills solve this by packaging procedural knowledge... into portable, version-controlled folders that agents load on demand" and spec: "skills-ref validate ./my-skill ... checks that your SKILL.md frontmatter is valid"; GitHub API: claude-plugins-official "Official, Anthropic-managed directory of high quality Claude Code Plugins", stargazers 37255
- url: https://agentskills.io/specification and https://api.github.com/repos/anthropics/claude-plugins-official
- source_type: primary
- published: retrieved 2026-10-01
- confidence: high

### [11] AGENTS.md became the universal instruction-file standard during this window — Claude Code added native AGENTS.md support (fallback when no CLAUDE.md) on 2026-09-18 after a 379-point feature request (issue #6235), making one file work across Codex, Cursor, Copilot, Claude Code et al.; the rollout was bumpy (a telemetry-gated reading bug made 485-pt HN news before being fixed)
- quote: HN titles: "Claude Code now reads AGENTS.md if there is no Claude.md" (741 pts, 2026-09-18) and "Claude Code reads AGENTS.md only when telemetry is on [fixed]" (485 pts, 2026-09-23); original "AGENTS.md – Open format for guiding coding agents" (837 pts, 2025-08-20)
- url: https://hn.algolia.com/api/v1/search?query=AGENTS.md&tags=story (stories 49760187, 49814947, 44957443) and https://code.claude.com/docs/en/changelog
- source_type: primary
- published: 2026-09-18 / 2026-09-23
- confidence: high

### [12] A supply-chain security surface for skills is now recognized and tracked: Tego's Skills Security Index (launched Mar 2026) is "the first public database analyzing the security risks of AI agent skills", scoring skills Pass/Low/Medium/High/Critical for prompt injection, credential exposure, excessive permissions implied by skill instructions — relevant before installing third-party skills into a repo that ships to buyers
- quote: "The first public database analyzing the security risks of AI agent skills. Every skill is evaluated against its stated purpose... findings report specific deviations from security best practices, such as Prompt Injection vulnerabilities, Credential Exposure, or Excessive Permissions."
- url: https://index.tego.security/skills/
- source_type: secondary
- published: 2026-03 (HN 2026-03-16)
- confidence: medium
