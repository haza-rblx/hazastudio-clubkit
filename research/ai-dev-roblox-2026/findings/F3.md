# F3: Roblox official AI capabilities as of late 2026 — Studio Assistant evolution, the built-in Studio MCP server, RDC 2026 AI announcements, and official Luau AI tooling

## Findings

### [1] The Roblox Studio MCP server is now built into Studio (no separate install) and gives external LLM agents ~25 tools across 8 categories: script edit, asset/AI generation, data-model exploration, Luau execution, playtesting, input simulation, docs, and session management
- quote: "The Roblox Studio MCP server is built into Roblox Studio. It implements the Model Context Protocol (MCP)... Once connected, your AI client can interact directly with your open Studio session, exploring the data model, writing scripts, running Luau code, and testing your game in play mode."
- url: https://create.roblox.com/docs/studio/mcp
- source_type: primary
- published: unknown (live docs, retrieved 2026-10-01)
- confidence: high

### [2] Concrete built-in MCP tool list (docs): script_read / multi_edit / script_search / script_grep; generate_mesh / generate_material / generate_procedural_model / wait_job_finished / search_asset / insert_asset / upload_image / store_image; subagent (explore + playtest types); search_game_tree / inspect_instance; execute_luau (datamodel_type Edit|Client|Server); get_studio_state / start_stop_play / get_console_output / screen_capture; character_navigation / user_keyboard_input / user_mouse_input; http_get (Roblox docs only) / skill; list_roblox_studios
- quote: "execute_luau — Runs Luau code in Studio. Returns either the result or an error. Requires specifying a datamodel_type (Edit, Client, or Server)." / "subagent — Launches a specialized subagent... Available types include explore (for codebase investigation and game state queries) and playtest (for running gameplay scenarios and verifying outcomes)."
- url: https://create.roblox.com/docs/studio/mcp
- source_type: primary
- published: unknown (live docs, retrieved 2026-10-01)
- confidence: high

- quote: "Quick connect supports the following clients: Antigravity, Codex CLI, Claude Code, Claude Desktop, Cursor, Gemini CLI, Visual Studio Code." / "Open Assistant. Click … ⟩ Manage MCP Servers. Turn on Enable Studio as MCP server."

- source_type: primary
- published: unknown (live docs, retrieved 2026-10-01)

- quote: "We've added new tools to the Studio MCP Server that will allow agents to iteratively plan, write, test, and modify your game. - quote: "The MCP Server is now built into Studio with no additional setup required. Assistant can start and stop playtests and simulate player input, enabling an end-to-end loop where it can reproduce issues, validate fixes, and iterate autonomously."
- url: https://devforum.roblox.com/t/assistant-updates-studio-built-in-mcp-server-and-playtest-automation/4474643

- quote: "Every MCP tool now takes a studio_id, so agents address Studios explicitly instead of relying on session state. Multi-Studio, multi-client workflows are more reliable, clients pick up the change automatically, Assistant Settings shows connected AI clients, and we fixed two stability issues."

### [7] Known limitation (acknowledged by Roblox staff): when Studio enters Play/Test mode it takes over the whole instance, so Edit-datamodel MCP tool calls fail during playtest; multiple agents on ONE Studio instance work but collide on mode switches
- quote: "if Studio goes into Play/Testing mode, that takes over the whole Studio and put its into the testing mode. Tools targeting Edit datamodel would fail while playtest is ongoing." (staff Urukeli); separate user report: "local Server and Client windows are not individually addressable, and execute_luau..."
- url: https://devforum.roblox.com/t/studio-mcp-multi-agent-improvements-and-connected-ai-clients/4820583
- source_type: primary
- published: 2026-08-19
- confidence: high
