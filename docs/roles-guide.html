Club Kit — Roles & Ranks

Cara kerja role/rank sekarang, dan langkah step-by-step nambah role baru lewat ClubKitConfig.

Pakai ← / →, Space, atau titik navigasi di atas untuk pindah slide.

Bagian A — Overview

Satu file yang diedit: ClubKitConfig

  • Path: ReplicatedStorage/Hazastudio_ClubKitConfig/ClubKitConfig.
  • File ini milikmu selamanya — Update Engine tidak pernah menimpa isinya; key baru cuma di-fill-forward.
  • Section yang relevan buat role/rank: Group, AdminUserIds, RoleCategories, SystemRoles, SpenderRoles, dan alias (CommandAliases / LegacyAliases).

Bagian A — Overview

3 konsep yang sering ketuker

Group rank

Rank Roblox di group kamu. Runtime cuma pakai ini buat Owner & Guest.

Kit role (/setrole)

Staff, CoOwner, Moderator, DJ, dst. Di-assign manual — ini sumber privilege command.

Membership

VIP / VVIP / Supreme dari Shop (beli/gift). Cosmetic + perk, bukan privilege staff.

Bagian A — Overview

Yang otomatis dari group: cuma 2

  • Owner — Group.OwnerUserId (match langsung, apapun rank-nya) atau rank ada di SystemRoles.Owner.groupRanks (default {255}).
  • Guest — rank ada di SystemRoles.Guest.groupRanks (default {0}) / bukan member group.
  • Role lain — Staff, CoOwner, Moderator, DJ, Lead Dance, Streamer, Influencer, dan role baru yang kamu tambah — semuanya manual lewat /setrole. Tidak ada yang otomatis dari rank group.
ClubKitConfig.Group.OwnerUserId = 987654321 -- selalu Owner, apapun rank-nya

ClubKitConfig.SystemRoles.Owner.groupRanks = { 255 } -- rank ini di group = Owner
ClubKitConfig.SystemRoles.Guest.groupRanks = { 0 }   -- rank ini di group = Guest

Bagian B — Nambah role

Goal contoh: tambah role Host

Host bisa /announce & /bring//to, tapi tidak bisa gift atau buka admin panel.

  • Persis privilege kategori Moderation yang sudah ada (canAnnounce + canTeleport, tanpa canGift/adminPanel).
  • Jadi kita tinggal tambah role baru di dalam kategori Moderation — tidak perlu bikin kategori baru atau ubah privilege apa pun.

Bagian B — Langkah 1 dari 6

Buka ClubKitConfig

  • Explorer → ReplicatedStorage → Hazastudio_ClubKitConfig → ClubKitConfig (buka Script Source).
  • Scroll ke section ClubKitConfig.RoleCategories.
  • Alternatif: plugin Club Kit → Config (kalau panel Roles sudah tersedia) — path hierarchy-nya tetap sama.
ReplicatedStorage
└─ Hazastudio_ClubKitConfig
   └─ ClubKitConfig  ← edit di sini

Bagian B — Langkah 2 dari 6

Copy blok role, ganti identitasnya

Di dalam kategori Moderation, copy salah satu blok roles[] yang ada (misal Moderator), tempel di bawahnya, lalu ganti field identitasnya.

-- ClubKitConfig.RoleCategories[2] ("Moderation").roles
{
    key = "Host",
    label = "Host",
    chatTag = "HOST",
    toolFolder = "HOST",   -- opsional, lihat langkah 3
    teamColor = "Electric blue",
    enabled = true,
    roleColor = { primary = "#3B82F6", secondary = "#93C5FD" },
},

key harus unik dan tanpa spasi — ini yang dicocokkan oleh /setrole.

Bagian B — Langkah 3 dari 6

Siapkan folder tools (opsional)

  • Kalau Host butuh Tool: buat folder ServerStorage/Tools/HOST/ lalu isi Tool yang mau di-hand out. Nama folder dicocokkan ke toolFolder (case-insensitive).
  • Kalau Host tidak butuh Tool sama sekali: kosongkan toolFolder = "" atau biarkan foldernya tidak ada — role tetap jalan (tag, warna, privilege kategori tetap aktif), cuma tidak ada Tool yang diberikan.

Bagian B — Langkah 4 dari 6 (opsional)

Alias command

Perlu kalau kamu mau /setrole menerima variasi ketikan lain buat Host (huruf kecil, singkatan, nama lama).

ClubKitConfig.CommandAliases = {
    -- ...existing...
    host = "Host",
}

LegacyAliases dipakai kalau kamu rename role yang sudah punya data lama tersimpan — bukan buat role yang benar-benar baru.

Bagian B — Langkah 5 dari 6

Assign ke player

  • Chat command: /setrole <player> Host (owner/admin only).
  • Atau: buka Admin Hub → tile Set role → pilih player → pilih role.
  • Tersimpan sebagai giftedRole di DataStore — override role hasil rank group, persist sampai di-/unsetrole.
/setrole HazaBuilds Host
/unsetrole HazaBuilds

Bagian B — Langkah 6 dari 6

Verify checklist

  • Overhead / chat tag player berubah jadi HOST.
  • Kalau kamu isi toolFolder: Tool HOST muncul di backpack player.
  • Privilege kategori Moderation jalan: Host bisa /announce & /bring//to, tapi /gift & admin panel tetap ditolak.
Berhasil jika: ketiga poin di atas benar dan tidak ada warning role di Output.

Bagian B — Pitfalls

4 hal yang gampang salah

  • Rank group 1–254 (selain 255) tidak otomatis jadi Staff/Host apa pun — cuma /setrole yang mengubah role kit.
  • Privilege nempel di kategori, bukan per role/player — dua role di kategori yang sama selalu punya privilege yang sama.
  • Jangan edit folder engine Hazastudio_ClubKit buat urusan role — semuanya cukup lewat ClubKitConfig.
  • Update Engine tidak pernah menimpa ClubKitConfig kamu secara penuh — role custom aman lintas update.
