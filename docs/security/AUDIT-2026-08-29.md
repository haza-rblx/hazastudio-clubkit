# Security audit — Hazastudio Club Kit, 2026-08-29 (engine 2.10.0 + unreleased ADR 0008 phase 1)

Method: five independent read-only passes over `src/` (remote surface — 67 handler sites; authorization model; secrets & HTTP; persistence; client-trust boundary + the new guards), each finding re-verified against the code before being listed here. Severity is about **impact in a live venue**, not theoretical purity.

Fixed the same day (unreleased, in `[Unreleased]`): every HIGH in the new ADR 0008 guards (noclip raycast, vehicle/seat exemption, RemoteStorm default, leaks) — see "Already fixed" at the bottom. Everything else below is **open** and waits for the owner's go.

## LOW / INFO

- `OverheadService.luau:73` HTTP call has no `Timeout` (60 s default) — add 5 s like siblings.
- `LicenseService.reportTamper` dedupes per **reason** for the whole server → only the first exploiter per server is ever beaconed (evidence suppression). Key on `reason .. actor_id`.
- `Secrets.luau` is git-tracked (only `*.local` ignored) — a filled-in copy can be committed by accident.
- `/dumpsaweria`, `/verifyspender`, `/addcash` are open to **any** player in Studio Team Test (only `/setrobux` has the live-DataStore guard).
- Player-name enumeration before permission check in `/gift` `/ungift` `/setrole` (`CommandExecutionService.luau:423/476/522`).
- Client can see `AdminUserIds`, `RankMap`, API URLs, `AntiTamper` settings (ReplicatedStorage config) — disclosure only; every action re-checks server-side.
- Sticker asset-id digit strings unbounded (`^%d+$`) — ~80 KB junk per player key max.
- `SignServer.luau:79` RemoteFunction lacks the tool-holder check that `RopeServer.luau:70` has.
- `GravityService.luau:483` accepts `NaN` speed (admin-only); carry calibration deltas have no absolute clamp (debug allowlist only).
- `NetworkManager` coalescing drops the second message to the same player in one frame when both lack `data.kind`; `CarryController.luau:110` passes two args and loses the payload — likely a functional bug, not security.
- `ClientGameplayReady` can be fired early to skip the caller's own overhead gate — harmless.

## What is solid (keep)

- **Secrets never reach the client**: every `Secrets` require is under ServerScriptService; no attribute/StringValue/remote carries a secret; only booleans are derived (`DonationController.luau:127-140`).
- **Actor identity is never client-supplied** in any of the 67 handlers; cross-player effects go through online-lookup + consent (couple/carry) or admin gates.
- **Five-gate pattern** (envelope → size → rate → dedupe → auth) in Admin, Music (15 handlers), Couple, Carry, AvatarLike, AvatarContext, Shop, Settings-update, Donation admin, Sync favorites.
- **ProcessReceipt** is fully server-derived (product↔tier from config, buyer = `receiptInfo.PlayerId`, in-memory + persistent receipt dedupe, `NotProcessedYet` on failure, license-gated grant).
- **Owner** = `OwnerUserId` / group rank 255 only; `game.CreatorId` is never an authorization input; `Owner` is not giftable (except H1).
- **DataStore keys** never derived from client text; all persisted free text filtered at write with the author's id; loads fail **closed** everywhere (no "load failed → grant defaults over real data").
- **License fail policy** matches its documented reasoning (optimistic only when never verified; hard-deny only on a definitive answer; `next_check_seconds` floored at 60).
- **TamperGuard** cannot be used to kick someone else; **NetworkManager** batching has no injection/replay surface.
- **XP / streak / likes** cannot be inflated from the client (no XP remote; server clock; self-like blocked; clamped totals).

## Already fixed today (ADR 0008 guards, unreleased)

- Noclip raycast excluded only the sampled player → a dancer standing in a doorway made every passer-by "clip". Now excludes **all** characters, requires the reverse ray to hit the **same** part (a cut corner exits into open air), and needs 3 events / 10 s.
- Seated players (vehicles, trams, elevators) are exempt from speed / teleport / noclip; buyer teleport pads get `MovementGuard.stampTeleport(character)` / the `ClubKitTeleportAt` attribute (documented in `Config.MovementGuard`).
- RemoteStorm counted third-party per-frame remotes → default action is now `log`; flip per place.
- Leaks: per-Sound `SoundId` connections now die with the Sound; `seen`/`seenPaths` capped; remote hooks cleared on destroy; AvatarGuard connections disconnected on leave; one deferred judge per character instead of one per accessory; soft-ban table pruned; sampler interval no longer drifts (`acc -= interval`).
- Rogue-sound beacons no longer attribute a sound parented into a character to that player (evidence framing).
