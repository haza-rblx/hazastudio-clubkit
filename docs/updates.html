Updates

Cara menarik engine terbaru ke place kamu, plus highlight perubahan tiap versi.

Update Engine (harian)

  1. Backup / pastikan ClubKitConfig & Secrets aman (plugin tidak replace penuh).
  2. Studio → Club Kit plugin → tab Engine → Check Update.
  3. Jalankan Update Engine, tunggu selesai (config fill-forward additive jika ada key baru).
  4. Save place. Verifikasi KitVersion (F9) = versi di atas.

Fresh install atau saat GUI/board berubah → insert .rbxm (jarang). Detail: Setup → Publish.

Yang tidak ikut diganti

  • Hazastudio_ClubKitConfig/ClubKitConfig.luau — nilai yang kamu isi dipertahankan; key baru diisi default (fill-forward).
  • Hazastudio_ClubKitSecrets/Secrets.luau — tidak di-touch.
  • StarterGui boards / Workspace models — sync engine Luau saja; asset visual tetap deploy manual bila berubah.

2.4.72 2026-08-08 Audit patch — DataStore data-loss fixes, boot hardening, 3 abuse-gate closures.

Fixed

  • Favorites, stickers, and level XP could be lost if the save failed right as a player disconnected — now retried automatically instead of dropped.
  • Client could hang on boot (stuck loading screen) if a remote or GUI folder was missing — now times out and soft-disables just that feature.
  • Dance panel on phones without the mobile wrapper GUI now falls back to the desktop layout instead of breaking dance sync entirely.
  • HotbarInventoryService no longer leaks character connections on every respawn.

Security

  • Sticker global pool and resolving a track by raw asset ID are now admin/DJ-gated — regular players' own uploads/requests still work, they just don't write to shared/global state.
  • Command Library now has a central permission gate, so a future command added without its own check doesn't become open to every player by default.
  • Fresh installs no longer inherit the kit developer's UserId as a default admin in the config template.
