Kolom Kit dibaca dari KitProduct.KitVersion. Map yang kit-nya tertinggal ditandai kuning, bukan dianggap rusak.

Cara baca: satu masalah = satu signature. Kolom Map menunjukkan di mana saja muncul. Masalah yang muncul di banyak map dengan jenis kit berarti perbaikannya di engine; jenis buyer-setup berarti perbaikannya di map.
Inti masalahnya: kit yang sama, tapi tiap map punya config, GUI, dekorasi, dan versi berbeda. Matriks ini dihitung dari data map, bukan ditulis tangan.
Aksi mengikuti yang sudah ada di kit (chat command + privilege adminPanel). Tombol di mockup belum terhubung.
