HAZASTUDIO CLUB KIT — FORM OWNER
================================
Isi lalu kirim balik (Discord / WhatsApp / email).
Jangan ubah nama field di kiri tanda =  (itu yang dipetakan ke ClubKitConfig).
Kosong = pakai default kit / dilewati.

Cara isi:
  Field    = nilai kamu
  Ya/Tidak = Ya atau Tidak
  0 / kosong = belum ada / tidak dipakai

KIRIM TERPISAH (jangan di grup publik):
  DonationApiSecret, GameDataApiSecret
