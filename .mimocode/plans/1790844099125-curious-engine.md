### Phase 5b — Data migration (one-shot script, AFTER engine install + BEFORE publish)

One-shot Luau script via `execute_luau` (server runtime atau edit) untuk port data dari DataStore lama ke Kit schema:

1. **DonationStats_Fixed_V3 → Kit Overhead `donatedRobuxTotal`**:
   - Read each key from `DonationStats_Fixed_V3` DataStore (format: `{ userId = totalRobuxDonated }`)
   - For each: `OverheadDomain.applyDonation(userId, amount)` via Kit's DonationRepository → writes to `Overhead_v1`
   - Log migration per player

2. **ManualPerks_V1 → Kit giftedMembership**:
   - Read each key from `ManualPerks_V1` DataStore (format: `{ VIP=bool, VVIP=bool, Patron=bool }`)
   - For each true: `OverheadDomain.addGiftedMembership(userId, tier, "manual_migration")` → Kit `Overhead_v1.giftedMembership`
   - VIP→Tier1, VVIP→Tier2, Patron→Tier3

3. **Dry-run first**: print all reads without writes, verify counts, user approve, then execute writes.
