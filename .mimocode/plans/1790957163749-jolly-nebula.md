## LANGKAH 1 — Prasyarat manual (2 hal, hanya bisa dilakukan user)

### 1a. Nyalakan "Enable Studio Access to API Services" di place BARU
Studio place baru → **File → Game Settings → Security** → ON → Save → **File → Publish to Roblox** (wajib publish minimal sekali).

*Tanpa ini, tidak ada cara menulis DataStore ke universe baru. Aku akan verifikasi sendiri setelahnya via `ListKeysAsync` di `instance:97m-v1y`.*

### 1b. Rebind lisensi + update provider_link di VPS (2 perintah)
SSH ke VPS, lalu:
```bash
# Ambil ADMIN_TOKEN
grep ADMIN_TOKEN /var/lib/clubkit/.env

# Pakai token itu di 3 request ini:
curl -X PATCH "https://api.hazastudio.id/admin/games/rust/license" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" -H "Content-Type: application/json" \
  -d '{"universe_id":"10768845395","place_id":"130748620444133","license_enforced":true}'

curl -X PATCH "https://api.hazastudio.id/admin/games/rust" \
  -H "Authorization: Bearer <ADMIN_TOKEN>" -H "Content-Type: application/json" \
  -d '{"provider_link":"https://saweria.co/BACKHOME"}'
```
Dan di dashboard Saweria `saweria.co/BACKHOME`: paste webhook `https://api.hazastudio.id/webhook/saweria/rust/<webhook_token>` (token dari `sqlite3 /var/lib/clubkit/db.sqlite "select webhook_token from games where game_key='rust'"`).

*Alternatif: kalau user kasih ADMIN_TOKEN di chat, aku yang jalankan semua request ini via script.*

**Aku berhenti di sini sampai 1a + 1b selesai. Lanjut otomatis setelah user konfirmasi.**

## Risiko & mitigasi
- **Throttle DataStore di Studio** (sudah terlihat: `StandardListGameServerThrottled`) → backoff 20 s, resume per store, kerja pelan. Estimasi: ratusan-ribuan key bisa 30-90 menit.
- **Place baru belum publish / API access off** → diblok di Langkah 2, tidak ada penulisan sebelum lolos verifikasi.
- **Boot dari tempat lain setelah rebind** → binding universe di-set eksplisit via PATCH (bukan menunggu first-boot), jadi tidak bisa ke-bind ke universe lain.
- **Config/secrets tidak disentuh** — place baru sudah membawa nilai yang benar (GameKey `rust`, ApiUrl `.../game/rust`, secrets sama). Tidak ada `set_script_source` ke buyer files.
